feat: Add comprehensive Tasks Kanban Board with backend integration

## Overview
Implemented a full-featured task management system with kanban board, inspired by vibe-kanban design patterns and integrated into the minimalist-sidebar-web-react application.

## Features Added

### Frontend Components
- **TasksEnhancedFinal**: Complete kanban board with 6 status columns (Backlog, To Do, In Progress, Review, Done, Cancelled)
- **Task Dialogs**: Create/edit task modal with full form validation
- **Task Detail Panel**: Side panel with Overview, Comments, Activity, and Time Tracking tabs
- **Advanced Filtering**: Real-time search, priority filters, and sorting options
- **Multiple Views**: Kanban, List, Calendar, and Analytics views
- **Status Tabs**: Active Kanban, All, Backlog, and Cancelled tabs
- **WIP Limits**: Visual indicators for work-in-progress limits per column
- **Drag & Drop**: Foundation for drag-and-drop task management

### Backend Integration
- **Database Schema**: 5 tables (tasks, task_comments, task_activities, task_time_entries, task_dependencies)
- **tRPC Routes**: 33+ API endpoints for full CRUD operations
- **Tasks Router**: Complete task management (create, read, update, delete, list, search)
- **AI Router**: AI-powered task suggestions and smart subtask generation
- **Recurring Tasks Router**: Automated recurring task creation
- **Database Queries**: Comprehensive query functions in db.ts

### Authentication System
- **Multi-Provider Auth**: Support for Manus OAuth, Google OAuth, and Demo mode
- **Demo Mode**: Instant preview without authentication setup
- **Flexible Configuration**: Easy switching between auth providers via environment variables
